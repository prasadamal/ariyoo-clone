# Google Play Data safety & Apple App Privacy — Ariyoo

Use when filling store forms. Adjust if you add analytics SDKs later.

## Google Play — Data safety

| Question | Answer |
| --- | --- |
| Collects data? | Yes |
| **Email address** | Collected, account management, not sold |
| **Messages / user content** | Collected, app functionality, not sold |
| **Photos** | Optional, user-selected, chat, not sold |
| **Location** | Not collected in current build |
| Encrypted in transit | Yes (HTTPS) |
| Users can request deletion | Yes — privacy@ariyoo.app |

## Apple — App Privacy (summary)

- **Contact Info:** Email — linked to user — app functionality
- **User Content:** Messages, photos — linked — app functionality
- **Identifiers:** User ID — linked — app functionality
- **Data used to track you:** No (unless you add ads/analytics later)

## Export compliance

Standard encryption only (HTTPS). App config sets non-exempt encryption false.
